# Nifty 50 Real-Time Market Terminal & AI Intelligence Suite

A real-time stock market workspace tracking the top 50 Indian market constituents (NSE India) with paper trading, sector heatmaps, interactive charts, and AI market analysis.

## Features
- **Real-Time Live Ticker Loop**: Simulated tick updates across top Nifty constituents and indices.
- **Interactive SVG Technical Charts**: Candlestick & line charts with timeframe selectors, MA(20) overlays, and RSI indicators.
- **Sector Weightage Heatmap**: Visual weight-proportional sector tiles.
- **Paper Trading Suite**: ₹10,00,000 INR starting portfolio capital with buy/sell execution and persistent unrealized P&L calculations.
- **AI Stock Co-Pilot**: Automated DCF Intrinsic Value calculator and catalyst analysis.
